3. Premiers Scripts Python

Qu'est-ce qu'un script Python ?

Un script Python est un fichier contenant des instructions exécutées ligne par ligne par l'interpréteur Python. L'extension officielle est .py.

Comprendre print()

print() est une fonction native Python utilisée pour afficher des informations dans le terminal.

Elle sert principalement à :

  • Afficher du texte
  • Afficher le contenu des variables
  • Déboguer un programme
  • Afficher des résultats utilisateur
print("Bonjour")

Résultat attendu dans le terminal :

Bonjour

Python lit la fonction print(), puis affiche le contenu entre parenthèses.

Comprendre input()

input() permet de demander une information à l'utilisateur depuis le terminal. 

nom = input("Quel est ton nom ? ")
print("Bienvenue", nom)

Ici Python attend que l'utilisateur tape une valeur au clavier.

Quiz rapide

Quelle fonction permet d'afficher du texte ?

4. Bases du langage Python

Comprendre les variables

Une variable est un espace mémoire qui stocke une donnée. Elle permet de réutiliser une information dans plusieurs parties du programme. 

nom = "Karim"
age = 32
prix = 19.99
admin = True

Explication détaillée :

  • nom contient du texte → type string
  • age contient un nombre entier → type int
  • prix contient un nombre décimal → type float
  • admin contient vrai ou faux → type bool

Comprendre les conditions

Les conditions permettent de prendre des décisions dans un programme. 

age = 18

if age >= 18:
    print("Majeur")
else:
    print("Mineur")

Python vérifie si la condition est vraie. Si oui, le bloc if est exécuté. Sinon le bloc else est utilisé.

Comprendre les boucles

Une boucle sert à répéter automatiquement des instructions. 

for i in range(5):
    print(i)

Python répète le bloc 5 fois. La variable i change automatiquement.

Comprendre les fonctions

Une fonction est un bloc réutilisable de logique. Elle permet d'éviter la duplication de code. 

def addition(a, b):
    return a + b

print(addition(5, 2))

return renvoie le résultat de la fonction.

Comprendre les listes

Une liste stocke plusieurs valeurs dans une seule variable. 

fruits = ["pomme", "banane", "orange"]
print(fruits[0])

Les index commencent à 0 en Python.

Comprendre les dictionnaires

Un dictionnaire stocke des données sous forme clé/valeur. 

user = {
  "nom": "Karim",
  "age": 32
}

print(user["nom"])

Ici la clé nom permet d'accéder à la valeur Karim.

5. pip et dépendances

Qu'est-ce qu'une dépendance ?

Une dépendance est une librairie externe ajoutée à un projet afin d'éviter de réécrire du code complexe.

Il existe plusieurs types de dépendances :

  • Dépendances natives Python
  • Modules de la bibliothèque standard
  • Packages externes installés avec pip

Bibliothèque standard Python

Python possède déjà énormément de modules intégrés. 

import math

print(math.sqrt(25))

Ici aucune installation n'est nécessaire.

Qu'est-ce que pip ?

pip est le gestionnaire officiel de packages Python. Son rôle est de télécharger, installer, mettre à jour et supprimer des librairies.

pip install pandas

pip télécharge automatiquement la librairie depuis le registre Python Package Index (PyPI).

Alternatives à pip

  • Poetry
  • Pipenv
  • Conda
  • uv

Ces outils ajoutent des fonctionnalités avancées comme la gestion d'environnement et le verrouillage des versions.

Quel est le rôle de Pandas ?

Pandas est une librairie spécialisée dans la manipulation et l'analyse de données.

Elle permet notamment :

  • Lire des fichiers CSV
  • Manipuler des tableaux de données
  • Analyser des statistiques
  • Générer des rapports
  • Nettoyer des données
import pandas as pd

fichier = pd.read_csv("users.csv")

print(fichier.head())

6. Projet CLI avec Pandas

Objectif du projet

Créer une application CLI qui récupère des données SQLite puis génère un rapport CSV avec Pandas. 

import sqlite3
import pandas as pd

conn = sqlite3.connect("database.db")

df = pd.read_sql_query(
    "SELECT * FROM utilisateurs",
    conn
)

print(df)

df.to_csv("rapport.csv")
python app.py

7. Mini Projet DevOps

Monitoring système

Créer un script Python qui vérifie automatiquement l'espace disque et génère des logs. 

import shutil

usage = shutil.disk_usage("/")

print("Total:", usage.total)
print("Utilisé:", usage.used)
print("Libre:", usage.free)
