Projet Python — Chaos Engineering API

Objectif du Projet

Construire une petite API locale Python qui simule volontairement des erreurs et des lenteurs afin de comprendre les bases du Chaos Engineering.

Ce mini projet permet d'apprendre :

  • les API Python
  • Flask
  • les routes web
  • les réponses JSON
  • les erreurs serveur
  • les délais réseau
  • les tests de stabilité
  • Accueil

C'est quoi Flask ?

Flask est un micro framework Python.

Son rôle est de permettre la création :

  • d’API
  • de serveurs web
  • d’applications backend
  • de routes HTTP

Flask est très utilisé car il est :

  • simple
  • léger
  • rapide à apprendre
  • parfait pour les débutants

Exemple d'utilisation réelle :

  • API REST
  • microservices
  • backend IA
  • outils DevOps
  • automatisation

Comprendre le Code Ligne par Ligne

1. Import Flask

from flask import Flask

Importer le framework Flask dans le projet.

2. Import random

import random

random permet de créer du comportement aléatoire.

3. Import time

import time

time permet de ralentir volontairement l'application.

4. Créer l'application Flask

app = Flask(__name__)

Initialise le serveur web Python.

5. Créer une route API

@app.route("/")

Définit une URL accessible dans le navigateur.

6. Créer la fonction API

def home():

Fonction exécutée quand quelqu’un appelle l’API.

7. Générer un hasard

hasard = random.randint(1, 5)

Python génère un nombre aléatoire.

8. Simuler une panne

if hasard == 1:

Une fois sur cinq l’API plante volontairement.

9. Simuler une API lente

time.sleep(temps_attente)

Le serveur attend plusieurs secondes avant de répondre.

10. Retourner du JSON

return { \"status\": \"success\" }

Flask convertit automatiquement le dictionnaire Python en JSON.
